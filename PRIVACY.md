# Приватность

## Что хранится на устройстве

- Настройки Ambilight (яркость, гамма, сглаживание, раскладка LED).
- Список контроллеров: имя, IP/hostname, порты, версия прошивки, число LED.
- Идентификатор выбранного контроллера и флаг пройденного onboarding.
- Журнал диагностики в памяти процесса (до 200 событий): код, время, техническая деталь (адрес,
  класс ошибки, задержка). Журнал исчезает при закрытии процесса.

Данные лежат в приватном хранилище приложения (DataStore Preferences). Резервное копирование
отключено (`android:allowBackup="false"`).

## Что не хранится и не передаётся

- Кадры экрана: анализируются в памяти и не сохраняются.
- Содержимое экрана, субтитры, названия видео.
- Пароли Wi-Fi, токены, API-ключи.
- Аналитика, рекламные идентификаторы, crash-репорты в облако.

Сеть используется только для:

- HTTP JSON API WLED в локальной сети;
- UDP DDP / WLED Realtime в локальной сети;
- mDNS-поиска `_wled._tcp` и явно запускаемого HTTP-сканирования локальной /24.

Входящие порты не открываются.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | локальные HTTP/UDP и определение сети |
| `CHANGE_WIFI_MULTICAST_STATE` | mDNS-поиск |
| `POST_NOTIFICATIONS` | видимое уведомление сессии (Android 13+) |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PROJECTION` | захват экрана по правилам Android |
| `WAKE_LOCK` | Wi-Fi lock во время сессии |

MediaProjection разрешение запрашивается системным диалогом при каждом старте и может быть отозвано.

## Экспорт диагностики

Отчёт содержит версию приложения, сводку устройства, время/код/техническую деталь событий. Он не
содержит кадров, токенов и паролей. Отправка выполняется только по действию пользователя через
системный share sheet.

## Удаление данных

«Настройки → Сбросить все данные» удаляет настройки, устройства и калибровку с устройства.
Контроллер WLED при этом не изменяется.
