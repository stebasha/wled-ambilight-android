соответствующих проектов и в экране «Настройки → Лицензии».

|---|---|

| Kotlin Standard Library, kotlinx.coroutines | Apache License 2.0 |
| kotlinx.serialization | Apache License 2.0 |
| OkHttp, Okio | Apache License 2.0 |
| JUnit 4 | Eclipse Public License 1.0 |
| MockWebServer | Apache License 2.0 |
| AndroidX Test, Espresso | Apache License 2.0 |

Исходный код приложения распространяется по лицензии MIT (см. [LICENSE](LICENSE)).

WLED — отдельный проект; прошивка не входит в этот репозиторий и не распространяется вместе с APK.
«WLED» используется только для описания совместимости.
