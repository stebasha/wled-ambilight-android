# Тестирование

## 1. Окружение

- JDK 17, Android SDK Platform 35, Build-Tools 35.0.0.
- Gradle wrapper 8.13.
- Для unit-тестов устройство не нужно; для instrumentation — эмулятор/устройство.

Windows (PowerShell), если инструменты лежат в `.tools`:

```powershell
.\scripts\build.ps1 testDebugUnitTest
```

Вручную:

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\path\to\android-sdk"
.\gradlew.bat testDebugUnitTest
```

## 2. Автоматические проверки

| Команда | Что проверяет |
|---|---|
| `.\gradlew.bat assembleDebug` | компиляция и упаковка debug APK |
| `.\gradlew.bat testDebugUnitTest` | 81 JVM-тест |
| `.\gradlew.bat lintDebug` | Android Lint, отчёт `app/build/reports/lint-results-debug.html` |
| `.\gradlew.bat assembleDebugAndroidTest` | компиляция instrumentation-теста |
| `.\gradlew.bat assembleRelease` | R8/shrink, release APK (неподписан) |
| `.\gradlew.bat connectedDebugAndroidTest` | запуск instrumentation (нужно устройство) |

### Покрытие unit-тестами

- `LedLayoutMapperTest` — углы, направления, реверс, нулевые стороны, невалидная геометрия.
- `FrameAnalyzerTest` — зоны четырёх сторон, чёрные полосы, чёрный кадр, вес края, отступ от края,
  лимит выборки.
- `ColorMathTest` — sRGB/linear, насыщенность, гамма, минимальная яркость, баланс, упаковка ARGB.
- `SmoothingTest` — Off/Fast/Balanced/Smooth, порог, ограничение шага, сброс при смене LED.
- `FrameCadenceTest` — ограничение FPS, latest-frame-wins, размеры анализа.
- `DdpPacketBuilderTest` — заголовок, offset/length, chunking, sequence, push, RGB-кодирование.
- `WledUdpPacketBuilderTest` — WARLS/DRGB/DNRGB, границы, ошибки конфигурации.
- `UdpLedOutputTest` — реальная отправка DDP через локальный UDP-сокет, счётчики, закрытие.
- `DiagnosticsRepositoryTest` — ограничение журнала, отсутствие данных экрана в экспорте.
- `WledHttpClientTest` — MockWebServer: info/state, неизвестные поля, HTTP 500, битый JSON,
  превышение размера, таймаут, недоступный хост, тело POST.
- `SettingsCodecTest` — round-trip, повреждение, легаси-формат, неизвестный enum, санитайзинг.
- `ValidationTest` — host/port/LED, границы настроек.
- `SubnetPlannerTest` — /24 без network/broadcast/self, приватные диапазоны.

## 3. Ручной чек-лист (требует оборудования)

### Демо без контроллера

Для проверки интерфейса без WLED есть HTTP-заглушка (только `/json/info` и `/json/state`, без UDP):

```bash
python scripts/fake_wled_server.py --port 8099
adb reverse tcp:8099 tcp:8099      # для эмулятора
```

Добавьте устройство `127.0.0.1:8099` (эмулятор) или `<IP-хоста>:8099` (телефон/TV в той же сети).
Заглушка не эмулирует LED-вывод и не заменяет проверку на реальном WLED.

Отмечайте фактически выполненное; не переносите непроверенное в «пройдено».

### WLED

- [ ] WLED 0.13.x / 0.14.x / 0.15.x: `/json/info` возвращает версию и `leds.count`.
- [ ] DDP 4048: тестовый цвет и сессия меняют все LED без сдвига индексов.
- [ ] WLED UDP 21324, DNRGB: раскладка > 480 LED, цвета без обрезки.
- [ ] WLED UDP 21324, WARLS: раскладка ≤ 255 LED.
- [ ] DRGB: ≤ 480 LED; > 480 — понятная ошибка, а не частичный кадр.
- [ ] Выключение/включение WLED во время сессии: ошибка `NETWORK_LOST`, повторный старт работает.
- [ ] Другой realtime-источник (Hyperion/приложение): предупреждение `REALTIME_OCCUPIED`.
- [ ] Выход из realtime после остановки: через ~2 с возвращаются обычные эффекты.
- [ ] Прошивка с паролем/закрытым API: понятная ошибка, без обхода.

### Android / TV

- [ ] Чистая установка: onboarding → добавление устройства → запуск.
- [ ] Отказ в MediaProjection: сессия не стартует, есть объяснение.
- [ ] Системная остановка проекции: сессия завершается, уведомление исчезает.
- [ ] Уведомление содержит «Стоп», остановка освобождает ресурсы.
- [ ] Поворот экрана: зоны пересчитываются, артефактов нет.
- [ ] Android TV/Google TV: все экраны доступны с D-pad, фокус виден, порядок логичный.
- [ ] Ввод IP с пульта: диалог и клавиатура удобны, кнопки достижимы.
- [ ] TalkBack: подписи у кнопок и статусов; масштаб текста 200% не ломает layout.
- [ ] 30–60 минут непрерывной работы: память стабильна, FPS не деградирует.
- [ ] Слабый Wi-Fi: пропуски кадров видны в статистике, приложение не зависает.

### DRM и контент

- [ ] Рабочий стол/локальное видео — цвета корректны.
- [ ] DRM-сервис — чёрный кадр, предупреждение появляется, обхода нет.
- [ ] Субтитры/чёрные полосы: компенсация работает предсказуемо, её можно выключить.

### Сеть

- [ ] mDNS находит WLED в обычной сети.
- [ ] Гостевая сеть/VLAN: mDNS не находит, ручное добавление работает.
- [ ] Скан /24 находит контроллер, не сканирует чужие диапазоны.
- [ ] UDP заблокирован: HTTP-проверка проходит, тест цвета сообщает `UDP_SEND_FAILED`.

### Калибровка

- [ ] «Зажечь LED 1» подсвечивает именно первый физический LED.
- [ ] «Бегущий огонёк» идёт по периметру в выбранном направлении.
- [ ] Реверс стороны исправляет нестандартный монтаж.
- [ ] Несовпадение количества LED с WLED показывает предупреждение.

## 4. Критерии приёмки MVP

1. Сборка из чистого checkout по README.
2. Ручное добавление WLED, проверка HTTP, сохранение.
3. mDNS или ручной путь при блокировке multicast.
4. Тестовый цвет на реальном контроллере.
5. Явное разрешение MediaProjection.
6. Незащищённое изображение анализируется, зоны соответствуют раскладке.
7. Нет накопления очереди кадров (latest-frame-wins).
8. Остановка прекращает отправку и освобождает ресурсы.
9. Ошибки сети/чёрного кадра/DRM объясняются.
10. Основные действия доступны с TV-пульта.
11. Unit-тесты алгоритма и протоколов проходят.
12. README содержит команды сборки/установки/тестов.
13. Нет ложных заявлений о неподтверждённых функциях.

Пункты 1, 11, 12 проверены автоматически; 2–10 и 13 требуют реального WLED/устройства, кроме
статической проверки кода.

## Ручная проверка 0.2.0 (зоны, Govee, управление)

- [ ] Монтаж по часовой стрелке от верхнего левого угла: «Бегущий огонь» идёт снизу справа налево
      и слева снизу вверх так же, как на схеме; цвета нижней и левой сторон совпадают с картинкой.
- [ ] Статичная картинка (пауза видео) 30 с: WLED не возвращается к своему эффекту.
- [ ] «Стоп»: WLED сразу возвращается к эффекту/пресету (а не через 2.5 с).
- [ ] Зона на том же контроллере (LED после ленты экрана): кнопка «Тест» зажигает только её диапазон.
- [ ] Пересекающиеся зоны: редактор показывает предупреждение, сессия запускает остальные выходы.
- [ ] Второй WLED и лампа Govee одновременно с основной лентой; выключение одного устройства не
      останавливает остальные (в статистике «Выходы» меньше общего числа).
- [ ] Govee: «Найти Govee» при включённом LAN Control находит лампу; «Тест» включает янтарный цвет.
- [ ] Управление WLED: питание, яркость, пресет, эффект применяются; при активном realtime видно
      предупреждение и работает «Выйти из realtime».
- [ ] Демо запускается без диалога захвата экрана и останавливается кнопкой «Стоп».
- [ ] Профиль: «Скопировать» → сброс данных → «Вставить» восстанавливает раскладку и зоны.
